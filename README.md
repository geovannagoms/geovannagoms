01 / Sobre mim
Sou Geovanna Gomes, estudante, escritora e criadora de projetos digitais. Estou aprendendo desenvolvimento web na prática, dando forma a ideias que combinam criatividade, identidade e conexão.
Meu projeto principal é o North-Net, uma rede social que estou desenvolvendo com HTML, CSS e JavaScript. Uso IA como apoio no processo e busco compreender o código, experimentar soluções e ganhar autonomia a cada etapa.
Agora: fundamentos de JavaScript, interfaces e desenvolvimento do North-Net.
Explorando: introdução à ciência de dados e possibilidades da inteligência artificial.
Além do código: poesia, fotografia e construção de universos literários.
O que me move: criar experiências que tenham personalidade e façam sentido para quem as usa.
Imaginar é o começo. Aprender a construir é o próximo capítulo.
